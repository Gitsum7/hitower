● Node // Cyber Armory

Cyber Armory

Free and open-source OSINT tooling, the public answer to "God's Eye." Every link goes to the project's official repo or site. HiTower doesn't host, run or vouch for these tools.

Rules of engagement

Use these tools only on yourself, on systems you own, or with written authorization, and only for lawful research, self-defense audits and journalism. Stalking, harassment, doxxing and unauthorized access are crimes (for example under 18 U.S.C. § 2261A and § 1030). Follow each site's terms and local privacy law. If you are being targeted, go to the Threat Lab.

iPhone ops

On iPhone, run the Python CLI tools (Sherlock, Maigret, holehe) in the free iSH app, a Linux shell for iOS: apk add python3 py3-pip, then pip install sherlock-project maigret holehe.
